# QuickCart Design System

## 1. Colors

| Use | Color | Code |
|---|---|---|
| Primary (buttons, logo) | Green | #16a34a |
| Secondary | Purple | #7c3aed |
| Background | Light grey | #f8fafc |
| Text | Dark grey | #111827 |
| Accent (badge background) | Light green | #dcfce7 |
| Error | Red | #dc2626 |
| Success | Green | #16a34a |

## 2. Typography

- Font: Arial, sans-serif
- H1: 32px / Bold (page titles)
- H2: 24px / Bold (cart total)
- Body: 16px / Regular
- Button text: 16px / Regular
- Small text: 14px / Regular (category names, badge)

## 3. UI Components

| Component | Where it is used |
|---|---|
| Navbar | Top of every page, links to Products, Cart and Login |
| Button | Primary (green), Outline (white with green border), Danger (red) |
| ProductCard | Products page, shows emoji, name, category, price and Add button |
| Category chip | Products page filter (All, Dairy, Bakery and so on) |
| Cart row | Cart page, shows item, quantity buttons, price and Remove |
| EmptyState | Cart page when the cart has no items |
| Form input | Login page (email and password) |
| Badge | Landing page "Delivery in 10 min" label |

## 4. UI Decisions

- Green is used as the main color to match a fresh grocery feel.
- The "10 min" badge is shown on the landing page to build trust and urgency.
- Emojis are used instead of product photos to keep the demo light and fast.
- The layout is mobile-friendly, and the navbar stacks on small screens.
